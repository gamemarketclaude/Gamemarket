Мой VPN

Добавьте на экран «Домой»

Нажмите Поделиться внизу Safari → На экран «Домой». Приложение появится рядом с остальными.

Скопируйте купленный ключ (vless://, vmess://, trojan://, ss://) или ссылку подписки и нажмите «Вставить ключ». Потом — большую кнопку.

Ваши ключи

    Ключи хранятся только на этом устройстве и никуда не отправляются.

    Приложение для подключения

    iPhone разрешает включать VPN только приложениям из App Store. Выберите, какое из бесплатных приложений откроется по кнопке «Подключить». Его нужно установить один раз.

    Не открылось?

    Скорее всего, ещё не установлено. Установите его из App Store (бесплатно) и нажмите «Подключить» ещё раз.
