# Бот листингов подарков (этап 1: Portals)

Бот следит за новыми лотами на Portals и присылает уведомление «ЛИСТИНГ»:
подарок, маркет, цена, модель, фон, символ, флор гифта, флор модели, последние продажи модели,
превью подарка, кнопки «Ссылка» и «Заблокировать подарок».

Бот **только читает** данные. Он ничего не покупает и не трогает деньги.
Отвечает только тебе (OWNER_ID).

## Что понадобится

1. **Токен бота.** Открой @BotFather → `/newbot` → придумай имя → скопируй токен.
2. **Свой Telegram ID.** Напиши @userinfobot, он пришлёт число.
3. **Отдельный Telegram-аккаунт, не основной.** Через него бот заходит на Portals.
   - Один раз открой в нём @portals и запусти маркет.
   - Зайди на https://my.telegram.org → API development tools → создай приложение → скопируй `api_id` и `api_hash`.
4. **Python 3.11 или новее.**

## Установка

```bash
cd gift-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # и впиши свои значения в .env
```

## Первый вход (один раз)

```bash
python -m scripts.login
```

Скрипт спросит номер **отдельного** аккаунта, код из Telegram и пароль 2FA (если он есть).
Потом он покажет 5 последних лотов с Portals. Если они появились, всё работает.

Скрипт создаёт файл `data/account.session`. **Это полный доступ к аккаунту:** никому его не отдавай.

## Запуск

```bash
python -m app.main
```

Бот напишет «🟢 Бот запущен». Первый опрос только запоминает текущие лоты. Дальше приходят только новые.

## Команды

| Команда | Что делает |
|---|---|
| `/price 0 10` | цена от и до (`/price - 10` — только верхняя граница) |
| `/collection Nail Bracelet, Plush Pepe` | только эти коллекции |
| `/model Vague Dream` | только эти модели |
| `/backdrop Black` | только эти фоны |
| `/symbol Kite` | только эти символы |
| `/backdrop -` | убрать фильтр |
| `/filters` | текущие фильтры |
| `/reset` | сбросить все фильтры |
| `/blocked` | заблокированные подарки и их разблокировка |
| `/pause`, `/resume` | пауза и продолжение |
| `/status` | когда был последний успешный опрос, ошибки |

## Важно знать

- **У Portals нет официального API.** Адреса взяты из открытых библиотек сообщества
  (portalsmp и faportalsmp) и могут измениться. Тогда бот напишет об ошибке в `/status`, и код придётся поправить.
- **Формат прямой ссылки на лот не подтверждён официально.** Он задаётся в `.env` (`PORTALS_LOT_LINK`).
  Если кнопка «Ссылка» открывает не тот лот, сообщи мне, и я поменяю шаблон.
- **«Последних владельцев» пока нет:** не нашёл надёжного источника. Добавлю, если найду.
- **Скорость:** опрос раз в `POLL_INTERVAL` секунд (по умолчанию 2, минимум 1). Если опрашивать слишком часто,
  Portals может заблокировать доступ.
